I wanted a place to write that I fully own — no algorithms deciding who sees it, no platform that might disappear one day. Just plain Markdown files I can edit myself.

## Why Markdown

No build tools, no accounts, no database. Every post here is just a plain text file with a bit of formatting. If I can write a text message, I can write a post here.
